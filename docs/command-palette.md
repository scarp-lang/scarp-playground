# Workspace command palette

Use **Commands** or Ctrl+Shift+P / Cmd+Shift+P to search existing workspace actions. The palette is local and does not execute an action while browsing. Arrow keys move between enabled commands, Enter invokes the selected action and Escape dismisses the modal. The native dialog isolates the background controls and returns focus to the invoker on close.

The action registry uses the same handlers as the visible toolbar, preserving existing confirmation, execution, storage and import rules. Unavailable commands are shown but cannot be invoked. The palette does not store search terms or require any network service.
