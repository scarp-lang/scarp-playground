# Editor preferences

Open **Editor preferences** from the header or command palette. Configure font size, line numbers, indentation, whitespace markers, editor height, wrapping, minimap, bracket colors, auto-closing brackets and scrolling. Apply explicitly or cancel to leave current settings unchanged. Reset defaults changes the pending draft until applied.

Only an allowlisted, versioned preference record is stored in browser local storage. This is independent of source autosave and contains no code, input or results. If storage is unavailable, settings still apply during the session. Existing Monaco models receive view and indentation options without replacing their text or resetting per-file undo history. Indentation preferences affect future edits, not automatic formatting.
