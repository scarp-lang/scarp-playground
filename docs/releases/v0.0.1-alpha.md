# Scarp Playground v0.0.1 (alpha)

**Experimental pre-release — not a stable or production-hardened compiler environment.**

Try the online preview: https://scarp-lang.github.io/scarp-playground/

## Exact compiler compatibility

- **Scarp compiler:** v0.0.5-alpha.3
- **Compiler source revision:** `7715c28df09c7703b39e14fddb963275b25df476`
- **Execution engine:** The actual Scarp Rust interpreter, compiled to WebAssembly
  with wasm-pack, running in a disposable browser Web Worker.
- **Compatibility guarantee:** Validated only against the pinned compiler;
  features present exclusively on the compiler development main branch may
  be unsupported.

## Included in this alpha

- React + TypeScript + Vite + Tailwind CSS, with dark and light themes.
- Monaco editor with Scarp syntax tokens, keyboard editing and source file tabs.
- Multi-file virtual `.srp` workspaces, relative imports and entrypoint selection.
- Real program standard output, standard error and structured compiler diagnostics.
- Working Scarp starter examples and single-file, size-limited URL sharing.
- Deterministic interpreter budgets, source-size limits and worker timeout.
- Locked JavaScript and Rust dependency graphs for CI and release builds.
- CI gates for type checks, linting, unit tests, native Rust bridge tests,
  browser WebAssembly builds and six real Chromium execution/UI tests.

## Important limitations

- No native Scarp executable generation, OS filesystem, program networking,
  packages or server-side code execution.
- Virtual projects are not persisted across browser reloads.
- Multi-file sharing is not implemented; short, single-file snippets only.
- A worker timeout and compiler budgets **do not** provide a hardened
  memory/process security sandbox. Do not paste secrets or rely on isolation
  against malicious source code.
- Mobile Chromium viewport has automated coverage, but a broader independent
  cross-browser, accessibility and security review has not been completed.

## Release integrity

This workflow tests the actual pinned Rust library natively, compiles the
WebAssembly bridge, runs the browser end-to-end suite, builds a static site and
attaches its `tar.gz` archive plus SHA-256 file to the GitHub pre-release.

The Playground version **must not** become v1.0.0 stable before the Scarp
compiler officially reaches its first stable release and independent
Playground security, compatibility, accessibility and quality gates pass.
